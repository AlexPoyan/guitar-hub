# Журнал рішень

```
ADR-001  UI-фреймворк: React замість Svelte
Дата: 2026-11-14  Статус: прийнято
Контекст: у стеку було «TypeScript + Vite, реактивність через Svelte (або без фреймворку)». Каркас Tauri створено з шаблону Vanilla + TypeScript. Потрібно обрати фреймворк для екранів (гриф як SVG, керування, стани).
Рішення: використовуємо React з TypeScript. Каркас лишається Vanilla, бо перша сторі лише про порожнє вікно; React підключається до Vite в сторі зі структурою UI (епік E0b).
Альтернативи: Svelte (легший, але новий для мене, а мета проєкту вчити Rust, а не фронтенд-фреймворк); Vanilla без фреймворку (більше ручної роботи зі станом на складних екранах); Rust-фронтенд (Yew, Leptos, Dioxus): відхилено, бо UI все одно працює у вебв’ю, а тести й макети розраховані на TypeScript, HTML і SVG.
Наслідки: React я вже трохи знаю, тож фокус лишається на Rust. Доводиться тягнути більше залежностей, ніж у Vanilla. Vitest і Playwright із розділу 10 працюють з React без змін у плані.
```
